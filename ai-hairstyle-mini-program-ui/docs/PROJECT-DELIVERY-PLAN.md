# AI 发型推荐与试戴系统交付计划

## 1. 项目目标（以拿下项目为导向）

- 体验目标：上传后 30 秒内看到 3-4 款可对比结果，用户可明确做选择。
- 业务目标：形成“试戴 -> 对比 -> 咨询/预约”的可追踪转化闭环。
- 交付目标：演示稳定（种子模式）、线上可扩展（真实模式）、过程可复盘（埋点与看板）。

## 2. 产品方案（推荐 + 自选双引擎）

- 推荐引擎：基于脸型/发际线/白发需求输出 TopN（4-6）并给出推荐理由。
- 自选引擎：支持按分类、预算、标签、材质筛选，用户可自主加入效果墙。
- 决策引擎：支持两款并排对比、原图滑动对比、局部微调（刘海/发际线/白发）。

## 3. 技术路线

- 前端：React + Vite + Tailwind（保留现有 UI 资产，快速演示与迭代）。
- 后端：Spring Boot + AI 路由（`seed` / `mock` / `real`）。
- AI 模式：
  - `seed`：预生成效果图，断网可演示（默认）。
  - `real`：DashScope 实时生成，失败自动降级 `seed`。

## 4. 四周执行计划（可压缩为两周）

### 第 1 周：演示可打动（已完成主体）
- 上传、分析、推荐、效果墙、并排对比、局部调整、门店 CTA 主流程打通。
- 种子模式 + 真实模式切换，保证“可演示”和“可上线”兼容。
- 验收标准：
  - 默认模式全流程不依赖外网可跑通。
  - 上传后自动生成推荐效果墙，至少 4 款。
  - 对比与反馈流程可完成提交。

### 第 2 周：可成交（本周重点）
- 强化推荐解释：每个推荐款具备可读推荐理由。
- 强化自选入口：搜索 + 分类 + 预算筛选后加入效果墙。
- 增加“方案沉淀”：收藏/候选清单（本地或会话级）与一键咨询。
- 验收标准：
  - 推荐和自选入口均可在 2 步内进入生成流程。
  - 用户可在 1 分钟内完成“看效果 -> 选款 -> 准备咨询”。

### 第 3 周：可运营
- 埋点体系：上传、推荐点击、加入效果墙、对比、反馈、咨询/预约全链路埋点。
- 数据看板：试戴完成率、对比率、咨询率、预约率。
- 门店策略：根据用户偏好与预算推荐门店/顾问。
- 验收标准：
  - 全链路关键节点埋点覆盖率 >= 95%。
  - 可输出日报级基础漏斗数据。

### 第 4 周：可规模化
- AI 质量策略：生成质量评分 + 自动重试 + 降级策略。
- 多场景模板：职场、日常、宴会、年轻化、遮白发专项模板。
- 性能优化：任务并行与结果缓存策略强化。
- 验收标准：
  - 失败可自动降级且不阻断核心流程。
  - 核心页面首屏和交互流畅度达到演示标准。

## 5. 当前代码任务分解

1. 推荐解释可视化（推荐理由卡片）。
2. 自选筛选增强（搜索 + 分类 + 预算）。
3. 候选清单与导流（收藏/咨询/预约联动）。
4. 埋点与日志（前端事件 + 后端接收）。

## 6. 风险与预案

- 真实 AI 不稳定：默认走 `seed`，`real` 失败自动降级。
- 图片质量差导致效果弱：上传页增加拍摄提示与错误提示。
- 演示现场网络问题：离线数据 + 种子图兜底。

## 7. 演示脚本（3 分钟）

1. 上传照片，展示 AI 分析和推荐理由。
2. 展示效果墙并行出图，进入并排对比。
3. 做局部调整（如“修发际线”），体现可定制能力。
4. 进入门店咨询入口，展示“从试戴到成交”的闭环。
